sysmanage-canary is installed, but not yet running

It needs its configuration first. What the installer did on this Mac is in /tmp/sysmanage-canary-install.log.

  1. Edit /usr/local/etc/sysmanage-canary.yaml: the server URLs, a read-only database role, the mail server and who to alert.
  2. Check it and send a test message: 
    sudo -u _sysmanage_canary sysmanage-canary \
    --config /usr/local/etc/sysmanage-canary.yaml --check-config
sudo -u _sysmanage_canary sysmanage-canary \
    --config /usr/local/etc/sysmanage-canary.yaml --test-email
  3. Start it (it then starts at every boot): 
    sudo launchctl bootstrap system /Library/LaunchDaemons/org.sysmanage.canary.plist

It logs to /usr/local/var/log/sysmanage-canary.log.
