SysManage Server is installed, but not yet running

What the installer found on this Mac (nginx, TLS, OpenBAO) is in /tmp/sysmanage-server-install.log. Then:

  1. PostgreSQL, if it is not installed: 
    brew install postgresql@16
brew services start postgresql@16
createdb sysmanage
  2. Configuration: copy the example and set the database and admin_userid (an email address): 
    sudo cp /etc/sysmanage.yaml.example /etc/sysmanage.yaml
  3. Database schema: 
    cd /usr/local/lib/sysmanage
sudo .venv/bin/python scripts/sysmanage_migrate.py
  4. TLS certificate, required before nginx will start: /usr/local/etc/sysmanage/tls/server.crt and server.key; then check with nginx -t.
  5. Start the server and nginx: 
    sudo launchctl load /Library/LaunchDaemons/com.sysmanage.server.plist
brew services restart nginx

To be told when the server stops working, install the separate sysmanage-canary package, ideally on another machine.
