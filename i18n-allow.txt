# i18n "intentionally English" allow-list — the escape hatch for the strict
# gate in scripts/i18n_strict.py (mirrors sysmanage-docs/assets/locales/
# no-translate.txt, which predates it).
#
# A value listed here may stay byte-identical to English in every locale
# without failing `make lint`.  Use it for things that genuinely do not
# translate: product and vendor names, CLI invocations, protocol tokens,
# file paths, format strings that are pure interpolation.
#
# One rule per line:
#   some.dotted.key        exact dotted key (JSON) or exact msgid (.po)
#   settings.*.command     fnmatch glob on the key
#   re:<regex>             regex matched against the ENGLISH value
# Full-line comments start with '#'.
#
# Keep rules TIGHT.  A broad glob silently re-opens the hole this gate exists
# to close — prefer three exact keys over one wildcard that also swallows the
# prose next to them.  Anchor value regexes with ^ and $.

# --- shell / package-manager invocations quoted verbatim in the UI ----------
re:^(sudo )?(apt-get|dnf|yum|zypper|apk|pkg|pkg_add|pkgin|brew|winget|snap)
re:^systemctl (start|stop|restart|enable|disable|status)

# --- product, vendor and protocol names --------------------------------------
re:^(SysManage|OpenBAO|Grafana|Graylog|OpenTelemetry|Prometheus)$
re:^(Ubuntu Pro|Launchpad|COPR|openSUSE Build Service|Homebrew|winget)$
re:^(bootc|rpm-ostree|osquery|Ansible|Velociraptor|Wazuh)$

# --- identifier lists and unit abbreviations that carry no prose -------------
# "DNF (Fedora/RHEL/CentOS 8+)" — package manager + distro names, all proper.
re:^DNF \(Fedora/RHEL/CentOS 8\+\)$
# "WSL: Ubuntu-24.04, LXD: ubuntu:24.04" — image identifiers, copied verbatim.
re:^WSL: [\w.\-]+, LXD: [\w.:\-]+$
# "{{minutes}}m {{seconds}}s" — interpolation plus conventional unit letters.
re:^\{\{minutes\}\}m \{\{seconds\}\}s$
# "{{target}} (Professional)" — the parenthetical is a licence tier name.
re:^\{\{target\}\} \((Community|Professional|Enterprise)\)$
# The bare "Enterprise" chip on the config-management engine rows (Phase 20.1)
# is the same licence-tier proper noun, standing alone rather than inside the
# parenthetical above. An exact key rather than a value regex, so it cannot
# accidentally bless the word "Enterprise" in ordinary prose elsewhere.
configManagement.engineEnterprise

# --- shells, hypervisors, protocols, package managers -----------------------
# Whole-value matches only (fullmatch).  These are names, not words: no locale
# renders "Zsh" or "bhyve" differently, and asking the translation service for
# one just burns a round-trip and comes back identical.
re:(Ba|K|Z|Tc|C|Fi)sh
re:(Bourne|Korn|Bourne Again|Friendly Interactive) Shell
re:(bhyve|KVM|QEMU|KVM/QEMU|LXD|LXC|WSL|VMM|vmd|VMM/vmd|libvirt|Xen|Hyper-V)
re:(syslog|journald|GELF|GELF TCP|GELF UDP|Syslog TCP|Syslog UDP|rsyslog)
re:(APT|DNF|YUM|Zypper|Pacman|Snap|Flatpak|Homebrew|Chocolatey|Scoop|winget|pkg|pkgin|pkg_add)
re:(APT|DNF|YUM|Zypper|Snap|Flatpak) \([A-Za-z0-9/ .+-]+\)
re:(Ubuntu|Debian|Ubuntu/Debian|Fedora|RHEL|CentOS|Rocky|AlmaLinux|openSUSE|SLES|Alpine|Arch|Gentoo|NixOS)
re:(FreeBSD|OpenBSD|NetBSD|DragonFly|macOS|Windows|Linux|Unix|BSD)
re:(PostgreSQL|SQLite|MySQL|MariaDB|Redis|Microsoft SQL Server|Oracle)
re:N/A

# --- cognates: identical in these locales, must still translate elsewhere ---
# Scoped deliberately.  "Status" IS the German and Dutch word; Spanish must
# say "Estado".  An unscoped rule here would bless the English everywhere.
de,nl: re:Status
de,nl,fr,it,pt,es: re:Version
de,nl,fr,it,pt,es,ru: re:URL
de: re:Name
nl: re:Naam
# "Interface" is the Dutch word too, so the correct nl value IS the English.
# It previously carried a Cyrillic с homoglyph instead of a Latin c, which
# looked translated to every check while being corrupted (found 2026-08-14).
nl: re:Interface \{\{number\}\}

# --- placeholder-dominant strings where identical IS the translation --------
# These looped forever in `make translate`: the backfill's _accept() holds back
# any result that comes back identical AND contains a placeholder, treating it
# as the service's English fallback.  For these the English IS correct — the
# non-placeholder part is either nothing, a unit letter, or a term borrowed
# unchanged ("Interface" in French, "hosts" in es/nl/pt, "Host" in German).
re:\{\{\w+\}\}s
re:\{\{\w+\}\} hosts?
re:Host \{\{\w+\}\}
re:Interface \{\{\w+\}\}
re:Violations — \{\{\w+\}\}
# "Version {{n}}" — "Version" is already blessed as a cognate for these
# locales above (de,nl,fr,it,pt,es), and the rest of the string is the number
# itself, so no correct de/fr rendering CAN differ from the English. Only de
# and fr are listed: the other locales' service output genuinely differs, and
# blessing them too would hide real gaps. An exact key, not a value regex, so
# it cannot bless "Version ..." prose elsewhere.
de,fr: configProfiles.versionLabel

# === residue triage, 2026-08-05 ==============================================
# Only names and identifiers below.  Ordinary words that happen to be cognates
# ("Status", "Server", "Details") are deliberately NOT here — those are real
# translation gaps in the locales where they came back English, and hiding
# them behind a rule would defeat the gate.

# --- i18n message KEYS leaking into the UI as display text ------------------
# These are dotted identifiers, not prose.  Worth fixing at the source (the
# code is rendering a key where it means to render a message) — until then
# they cannot be translated because they are not language.
re:openbao\.[a-z_]+
re:vault\.[a-z_]+

# --- shell program names (rendered next to their path, e.g. "(/bin/false)") --
# hostAccount.shellFalse labels /bin/false and sits alongside Bash/Csh/Ksh/Zsh,
# all left untranslated.  11 of 13 locales had rendered it as the BOOLEAN
# ("Falsch", "Faux", "Ложь") — and the Arabic file held Chinese text — which is
# a mistranslation of a program name, corrected 2026-08-05.
re:False

# "Edition" is the German word too — Microsoft's own German Windows UI uses it
# for exactly this control.  Scoped to de: Spanish wants "Edición", French
# "Édition", so an unscoped rule would bless the English in all 13.
de: re:^Edition$

# Pure interpolation: two placeholders, a separator, and a third placeholder.
# There is no prose here to translate — the description it carries is already
# localized by the engine that produced it.
re:^\{\{step\}\}/\{\{total\}\} · \{\{description\}\}$

# --- nav / settings labels that are the SAME WORD in some target languages ---
# Exact keys, not a glob on `nav.*` or `settings.cat.*`: the neighbouring
# labels DO translate (fr Analyses, de Einblicke, de Verwaltung, fr Général)
# and a wildcard here would stop the gate noticing if one of those regressed.
#
# FIPS is the acronym of a US federal standard and is written "FIPS" in every
# Latin-script locale; ru/ar/hi/zh_CN carry transliterations instead, which
# this rule permits but does not require.
nav.fips
# "General" is the Spanish word; fr Général and de Allgemein differ.
settings.cat.general
# "Administration" is the French word; de Verwaltung and es Administración differ.
nav.cat.admin
